# F-Droid submission

`uk.octopuslive.app.yml` is the recipe F-Droid uses to build the app from this repository.
It goes in F-Droid's `fdroiddata` project as `metadata/uk.octopuslive.app.yml`.

The first merge request was closed until the app has 3 months of development: reopen it,
or open a new one, from **17 January 2027**. Before submitting, update `versionName`,
`versionCode` and `commit` (the full commit hash of the latest `v` tag) to the latest release.
